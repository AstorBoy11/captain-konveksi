# Captain Konveksi

Website company profile dan kalkulator harga untuk bisnis konveksi. Membantu memudahkan pelanggan menghitung harga produk berdasarkan spesifikasi yang dipilih.

## Fitur Utama

### 1. Kalkulator Harga Interaktif
- **Berbasis Teks**: Menggunakan input teks biasa (seperti chat) untuk memasukkan spesifikasi produk.
- **Real-time Updates**: Harga diperbarui secara otomatis saat spesifikasi diubah.
- **Jenis Produk**: Mendukung berbagai jenis pakaian seperti Polo Shirt, Kemeja, Jaket, Hoodie, Sweater, Jersey, Celana Training, Rompi, dan Tas.
- **Opsi Kustomisasi**: 
  - **Kerja Sama**: Pilihan antara "Maklun" atau "Produksi Full".
  - **Jenis Bahan**: Pilihan bahan berkualitas (Briva, Drill, Ripstop, Cotton, Fleece, Lotto, Polyester).
  - **Lengan**: Pendek atau Panjang.
  - **Kerah**: Beragam pilihan model kerah.
  - **Kombinasi**: Fleksibilitas dalam pemilihan warna dan kombinasi desain.
  - **Detail Tambahan**: Bordir, Printing Sablon, Label, dan Upgrade Ongkos.

### 2. Form Notifikasi & WhatsApp
- **Notifikasi Otomatis**: Memberi tahu admin tentang pesanan baru dan detail spesifikasinya.
- **Integrasi WhatsApp**: Tombol "Hubungi via WhatsApp" yang terintegrasi langsung dengan sistem (menggunakan `wa.me`).
- **Pesan Pre-filled**: Pesan WhatsApp yang sudah disiapkan dengan detail pesanan, memudahkan pelanggan untuk mengirim pesan.

### 3. Navigasi Cepat
- **Sticky Header**: Header navigasi selalu terlihat di bagian atas saat menggulir layar.
- **Menu Navigasi**: Akses cepat ke berbagai kategori produk dan halaman utama:
  - Pakaian Olahraga
  - Pakaian Promosi
  - Kemeja
  - Jaket
  - Almet
  - Hoodie & Sweater
  - Seragam Sekolah
  - Tas
  - Kapasitas Produksi
  - Paket Tim
  - Artikel

### 4. Desain Responsive
- **Mobile-First**: Tampilan dioptimalkan untuk perangkat seluler.
- **Adaptif**: Desain menyesuaikan dengan berbagai ukuran layar (responsive design).
- **Viewport-Aware**: Mendukung safe area padding pada perangkat modern.

### 5. Estimasi Waktu Produksi
- **Kapasitas Pabrik**: Menampilkan informasi mengenai berapa banyak produk yang bisa diproduksi per periode (hari/minggu).
- **Proses Produksi**: Detail tahapan produksi dari desain hingga pengiriman.

## Teknologi yang Digunakan
- **HTML5**: Struktur halaman.
- **CSS3**: Styling, animasi, dan layout responsif (Flexbox & Grid).
- **JavaScript**: Logika kalkulator harga, validasi form, dan interaktivitas.
- **Integrasi WhatsApp**: Menggunakan `wa.me` untuk komunikasi langsung.
